This is a mini linux shell created by Er. Somanath Sara.
Initially at 2nd year of B.tech it is build by Gudu.
The project Architecture is simple.
The main Thread is inside the shell.py.
All the other Functions are defined in commands.py.
Rather that that another helping functions like piped commands are defined inside utils.py.
All the cmd histories are stored inside history.txt
The project structure is Look like this


MINI LINUX SHELL

        |----utils.py
        |----history.txt
        |----help.txt
        |----.env
        |----.gitignore
        |____README.md
